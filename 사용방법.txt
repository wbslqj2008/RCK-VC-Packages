RCK VC Add-on 배포 방법
=======================

[최초 1회: 저장소 관리자]
1. 이 폴더의 내용을 GitHub 저장소 루트에 올립니다.
2. GitHub 저장소 > Settings > Actions > General로 이동합니다.
3. Workflow permissions에서 "Read and write permissions"를 선택하고 저장합니다.
4. 저장소가 Public인지 확인합니다.
5. VC Addon Manager의 Manifest URL은 아래 형식입니다.
   https://raw.githubusercontent.com/<계정>/<저장소>/main/manifest.json

[애드온 업데이트 담당자]
1. packages\애드온이름\payload 폴더에서 기존 DLL을 새 DLL로 교체합니다.
2. tools\패키지_생성.bat를 더블클릭합니다.
3. 애드온 번호를 선택하고 새 버전을 입력합니다. 예: 1.1.0
4. dist 폴더에 만들어진 ZIP을 확인합니다.
5. GitHub > Releases > Draft a new release로 들어갑니다.
6. 새 Tag를 만듭니다. 예: addons-2026.07.30-01
7. ZIP을 첨부한 뒤 Publish release를 누릅니다.
8. GitHub Actions가 다음 작업을 자동 처리합니다.
   - ZIP 내부 package.json 검사
   - SHA-256 계산
   - 다운로드 URL 작성
   - manifest.json 갱신
   - main 브랜치에 자동 Commit

중요
----
- ZIP을 올린 뒤 Release를 게시해야 자동화가 실행됩니다.
- 이미 게시한 Release에 ZIP을 추가했다면 Release 설명을 한 번 수정하거나,
  Actions > Release 패키지 Manifest 자동 갱신 > Run workflow에서 Tag를 입력합니다.
- 같은 버전의 ZIP을 교체하지 말고 1.0.0 -> 1.0.1처럼 버전을 올리십시오.
- 담당자는 SHA-256 값을 계산하거나 manifest.json을 직접 수정할 필요가 없습니다.
